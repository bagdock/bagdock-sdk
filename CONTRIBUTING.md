# Contributing

This repository is a generated, one-way mirror. The source of truth is
Bagdock's private monorepo, not this repo. Everything here is assembled and
pushed by an automated sync job in that monorepo.

Because of this, pull requests opened here cannot be merged. Any PR will be
closed automatically with a comment pointing back to the monorepo.

## Reporting bugs and requests

Issues are welcome and read. If you find a bug, have a feature request, or
want to ask a question about `@bagdock/sdk`, open an Issue in this repo. It
will be triaged and, where relevant, carried into the monorepo's own tracker.

## Releases

Releases are automated and tokenless. Publishing to npm uses trusted
publishing, so no maintainer holds a long-lived publish token for this
package.
